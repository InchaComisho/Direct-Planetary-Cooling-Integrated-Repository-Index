## 概要

地球直接冷却（DPC）は、地球温暖化を単なる「大気中ガス濃度の問題」としてだけではなく、**惑星規模の熱蓄積と冷却システムの故障**として捉える。

中核となる考え方は単純である。

```text
地球が過熱している原因が、自然の冷却・循環システムの崩壊にあるなら、
唯一の現実的な解決策は、
それらの物理的冷却機構と自然循環機構を直接補完・回復することである。
```

DPCは、以下の三本柱を中心に構成される。

```text
1. Ocean Breathing Systems（OBS）
   深海エアレーションと鉛直循環によって、海洋熱の放出、酸素供給、海洋呼吸を回復する。

2. Ultrasonic Mist Cooling（UMC）
   微細で制御可能な水ミストにより、都市・半乾燥地・海面周辺の気化熱冷却を行う。

3. Desert and Semi-Arid Regeneration
   腐植形成、土壌微生物回復、多種植生により、長期的な炭素固定と局所冷却を再構築する。
```

すべての構成要素は、以下の設計思想に基づく。

- モジュール式
- 可逆的
- 自然整合的
- 既存技術で検証可能
- 大気エアロゾル散布のような高リスクな気候操作に依存しない
- オープンに共有・改良可能

DPCは、壊れた自然循環を補完し、自然が再び自律的に働ける条件を整えるための技術体系である。

```text
海洋では、呼吸と鉛直循環を補完する。
都市では、気化熱冷却と水循環を補完する。
砂漠・半乾燥地では、腐植・微生物・植生・保水を補完する。
```

自然を置き換えるのではなく、自然が再び働ける場を整える。

これが、地球直接冷却の基本姿勢である。
